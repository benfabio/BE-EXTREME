# BE-EXTREME

Here are the R scripts developed to build the **BE-EXTREME** dataset and reproduce the analyses and figures presented in:

> Benedetti et al. *BE-EXTREME : Climate and extreme event reconstructions (1950-2024) for the grasslands and forests of the Biodiversity Exploratories*. in preparation for *Earth System Science Data* (ESSD).

---

## Overview

This repository contains the main R scripts for building, processing, modelling, and visualizing the data underlying BE-EXTREME. It accompanies (but does not duplicate) the dataset itself, which is archived here **[Add Zenodo link here]**.

This is a curated public subset of a larger private development repository. Scripts here cover data processing, index computation, statistical modelling, and figure generation relevant to the published paper; exploratory and unpublished analyses are not included.

---

Scripts are **NOT** numbered to reflect the intended execution order yet. Pleasr find here a brief description of each script's purpose:

| Script | Purpose |
|---|---|
| `Script#1.3_BEO_inter-EP_distances_compute.r` | Compute the distances (in km) between experimental plots (EPs) based on their spatial coordinates (lat./long.) |
| `Script#1.4_BEO_forest_EPs_stand_age_compute.r` | Loads BExIS dataset **#17486** (main tree stand age) and combines it with outputs from **Script#1.3** to obtain the base dataset that will later enable you to examine variations in daily offsets driven by the tree canopy and associated with microclimatic effects |
| `Script#2.5_BEO_local_ClimateData_extracte.R` | Uses the **query_timeseries()** function of the 'rTubeDB' R package to download the hourly temperature, precipitation and soil moisture data measured by the Biodiversity Exploratories' weather stations |
| `Script#4.4.1_BEO_offsetxstand_age_MTS_table_assemble.r` | Loads the dataset created by **Script#1.4** and combines it with estimates of mean offsets (Tgrass - Tforest) based on the daily parameters' values of the top 5 closest grasslands (also given by the data generated by **Script#1.4**) |
| `Script#4.4.3_BEO_offsetxstand_age_MTS_modelle.r` | Loads the datasets created by **Script#4.4.1** and applies **GAMMs** to model daily variations in parameters' offsets |
| `Script#4.5.2_BEO_offsetxstand_age_MTS_predicte.r` | Re-loads the prediction tables from **Script#4.5.1** and the **GAMM** objects (**Script#4.4.3**) to predict the daily offsets of max/min Ta_10, Ta_200, SM_10, Ts_05, Ts_10, Ts_20 all the way back to 1950  |
| `Script#5.1_BEO_ERA5-Land-DEU_hourly_data_processe.r` | Extracts, for every EP, the **hourly ERA5-Land data** that Adrian Huerta (Klimatologie Group, GIUB) downloaded and stored on the climcal server |
| `Script#5.2_BEO_ERA5-Land-DEU_daily_stats_compute.r` | Loads the time series of hourly ERA5 Land data generated by **Script#5.1** and uses them to compute daily statistics (mean/min/max/CV) |
| `Script#6.3.2_BEO_E-OBS_daily_data_E-OBS+ERA5Land_compare.r` | Compares the daily temperature and precipitation data from **E-OBS** and **ERA5-Land** extracted at the EP location against the locally-measured data |
| `Script#6.3.3_BEO_E-OBS_daily_data_E-OBS_ERA5-Land_biases_compute.r` | Computes the biases in the daily parameters' values between E-OBS/ERA5-Land and observations (modelled values - observed values) |
| `Script#6.3.4_BEO_E-OBS_daily_data_E-OBS+ERA5Land_analyze.r` | Analyses the biases computed in **Script#6.3.3** |
| `Script#6.4.2_BEO_E-OBS_quantile_mappe.r` | Performs **quantile mapping (QM)** with the 'qmap' R package to correct the daily climatic values (i.e., daily minimum temperature) from E-OBS (air temperature, precipitation), and ERA5-Land (all other parameters) |
| `Script#6.4.3_BEO_E-OBS_daily_data_quantile_map_compare.r` | Evaluates the daily climatic values corrected through the 4 quantile mapping (QM) strategies against the locally-measured daily climatic values |
| `Script#6.4.4_BEO_E-OBS_daily_data_quantile_map_combine.r` | Combines the EP-level time series coming from each of the four QM strategies with the local measurements for every climatic parameter to obtain the **final reconstructions for the grasslands** |
| `Script#6.4.5_BEO_E-OBS_daily_forest_corrected_data_combine.r` | Combines the corrected EP-level climate time series with the local measurements to obtain the **final long-term reconstructions data for the forests**, as we did for the grasslands (**Script#6.4.4**) |
| `Script#7.1.1_BEO_fixed_baseline_extremes_finde.R` | Identifies and quantifies **extreme climate events** (**ECEs**) based on a **fixed** baseline approach |
| `Script#7.1.4_BEO_shifting_baseline_extremes_finde.r` | Identifies and quantifies **extreme climate events** (**ECEs**) based on a **shifting** baseline approach |
| `Script#7.4_BEO_SPEI_compute.R` | Computes the **Standardised Precipitation-Evapotranspiration Index (SPEI)** based on the daily reconstructions of temperature and precipitation, for both grassland and forest EPs |
| `Script#9.0_BEO_figures_make.r` | R script to generate the figures (main and suppl.) of the ESSD Data Paper in prep. |

## Requirements

- R (≥ 4.5.X recommended)
- Key packages include: `tidyverse, reshape2, lubridate, lme4, mgcv, SPEI, etc.`

Install dependencies with:

```r
install.packages(c("tidyverse","data.table","reshape2","lubridate","zoo","parallel","qmap","lme4","mgcv","terra","SPEI","viridis","scales"))
```

---

## Usage

1. Clone this repo.
2. Update file paths at the top of each script to point to your local copy of the input data (see **[Add Zenodo link here]**).
3. Run scripts to reproduce the processing pipeline, statistical models, and figures from the paper.

Scripts are documented with inline comments; each corresponds to a specific step, table, or figure referenced in the manuscript (cross-references noted where applicable).
